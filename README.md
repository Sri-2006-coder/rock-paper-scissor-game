# Rock Paper Scissors - Full Stack Web Application

A full-stack Rock Paper Scissors game built using React and Spring Boot.

## Features

- Interactive Rock, Paper, Scissors gameplay
- Real-time score tracking
- Best-of-5 match system
- Match history tracking
- Modern responsive UI
- REST API integration between frontend and backend

## Tech Stack

### Frontend
- React
- Vite
- CSS3

### Backend
- Spring Boot
- Java
- REST APIs

## Project Structure

Frontend:
- React
- Vite
- CSS

Backend:
- Spring Boot
- Java

## How to Run

### Backend

```bash
mvn spring-boot:run
```

Runs on:

```
http://localhost:8080
```

### Frontend

```bash
npm install
npm run dev
```

Runs on:

```
http://localhost:5173
```
